# Tanian Dashboard

Aplikasi dashboard UMKM pertanian berbasis Flutter.

## Fitur
- Splash Screen
- Login, Register, Forgot Password
- Dashboard
- CRUD Produk
- Upload Foto Produk
- Laporan Penjualan
- Profil UMKM
- Responsive UI
- REST API (JSON Server)
